Source Code

Currently we only provide source code for the theora reference implementation. There are no official binaries.

The latest release is 1.0 alpha 3. Despite being alpha, this release is quite stable and suitable for real use. The api is subject to revision, but the files the encoder produces will always be supported.

  • libtheora-1.0alpha3.tar.bz2
  • libtheora-1.0alpha3.tar.gz
  • libtheora-1.0alpha3.zip
To compile this you will also need the latest versions of the ogg and vorbis libraries.
  • libogg-1.1.1.tar.gz
  • libvorbis-1.0.1.tar.gz

Older releases are available here.
