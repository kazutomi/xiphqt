Current Unstable Release

1.1.7

The changes for this release include:

  • Generic optimizations in the encoder
  • ARM-spefific optimizations (gcc inline assembly)
  • Optional shortcuts in the encoder sacrificing quality for speed
  • Fixed-point improvements (perceptual enhancement converted)
  • Reduction in memory usage
  • Symbian code now uses the same API
  • Several bug fixes
