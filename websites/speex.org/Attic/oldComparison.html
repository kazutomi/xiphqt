Definitions:
multi-rate: Allows the codec to change bit-rate dynamically at any moment
embedded: Allows decoding of only the narrowband part from a wideband stream
VBR: Variable bit-rate
FE: Robust to frame erasure (aka packet loss)
bit-robust: Handles bit corruption gracefully (applies to wireless, but not IP)

Special features:

Speex
Support for intensity stereo encoding
Support for 32 kHz sampling

iLBC
With iLBC, all frames are encoded completely independently. While this provides better quality at extreme packet conditions (>10%), it makes the codec sub-optimal in "clean" conditions.
