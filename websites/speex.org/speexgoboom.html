Speex

About

The Speex project aims to build an open-source, patent-free voice codec. Unlike other codecs like MP3 and Ogg Vorbis, Speex is specially designed for compressing voice at low bitrates in the 8-32 kbps/channel range. Possible applications include VoIP, internet audio streaming, archiving of speech data (e.g. voice mail), and audio books. In some sense, it is meant to be complementary to the Ogg Vorbis codec.

The main features of Speex are:

  • open-source, patent and royalty free
  • optimized for speech
  • support for both narrowband (8 kHz) and wideband (16 kHz)
  • many available bit-rates ranging from 6 kbps to 42 kbps
  • Voice Activity Detection (VAD)
  • Discontinuous Transmission (DTX)
  • Variable Bit-Rate operation (VBR)

If you are interested in participating in the project, contact the Project Lead, Jean-Marc Valin, or join our mailing list. At the moment, we are seeking developers with signal processing and speech coding knowledge, people with knowledge about patents, and people who can help integrate Speex with existing standards.

Currently, LinPhone, OpenH323, and GnomeMeeting are some of the projects currently using Speex. For a complete list of projects with both current and planned Speex support, visit the Projects page.

Headlines

New Site Redesign

October 9, 2002

The old site had a bug that IE 6 didn’t interpret the same way as other browsers, which prompted a total rewrite of the site. However, speex.org now uses the latest web standards, including XHTML 1.1 for content, CSS for presentation, and the occasional PNG graphic.

Now a member of Xiph.Org

October 11, 2002

Speex is now a project of the Xiph.Org Foundation, a non-profit company devoted to the creation, production and maintenance of open multimedia standards. In addition to moving to Xiph, the Speex source is now licensed under Xiph.org's variant of the BSD license.

Also, today marks the release of Speex Beta One! It is available via the download page as source and pre-compiled binaries. The API and bitstream are in “soft freeze”, and there’s new support for vorbiscomment. Enjoy!

Speex 0.8.1 Released

November 4, 2002

Speex 0.8.1 released. This release fixes a bug in the new 0.8 API (speex_mode_query()). Users of speexenc and speexdec don’t need to upgrade but users of libspeex (either directly or through another application) should.
