1. Status Updates

1.1. Jean-Marc Valin

Jean-Marc fixed a few minor bugs in Speex, made speexdec more robust against corrupted files, and wrote documentation for Speex.

1.2. Michael Smith

Michael committed an avalanche of changes to Icecast 2. These changes add mountpoint fallbacks and a more flexible format infrastructure to allow MP3 metadata support, and fix memory leaks and other miscellaneous bugs.

2. Interesting Discussions

2.1. Icecast 1 vs Icecast 2

In this message, Aaron Gaudio expressed his frustration at the state of limbo in which Icecast development appears to be. On the one hand, Icecast 1 development has ceased, whereas Icecast 2 development is very active, but not visible on the web site due to maintainer problems, and Aaron misses some Icecast 1 features in Icecast 2.

The thread that ensued was rather long and came dangerously close to becoming a flame war, so here is a very condensed summary of the main points:

  • It is an unfortunate reality that Icecast 1 development has been abandoned, but a GPL project, such as Icecast, never dies. If Icecast 1 has bugs that you need fixed, and Icecast 2 doesn't meet your needs yet, there is nothing, except for lack of technical know-how, to stop you from fixing the bugs.

  • Icecast 2 is in active development, but it has, unfortunately, no prominent public forum apart from the mailing list. This problem is in the process of being addressed, as the web site is being redone.

Nobody denies that the current situation is unpleasant, but it is being worked on as quickly as possible.

3. Recent Developments

3.1. New Software with Ogg Vorbis Support

Two new software projects with Vorbis support have been posted on vorbis.com:

  • GiantDisc is a package of software tools which consists of a Linux server scripts to manage and play Ogg Vorbis tracks, and a Palm remote control application which allows to fully control the audio server.

  • Aniplayer is a multimedia player for Atari. Its most recent version adds support for the Ogg Vorbis format.

3.2. DVD Player with Ogg Vorbis Support

This is still not the kind of hardware support that Ogg Vorbis fans are really craving for, but it's a big step in the right direction. According to this Q&A page, the KiSS DP-450 DVD player by Kiss Technology supports Ogg Vorbis playback in the newest firmware.

Seeing Ogg Vorbis make its way into an ever growing number of mainstream applications is a good sign, and we hope it sets the trend for even more exciting news in 2003, which we at Xiph call the Year of the Fish!
