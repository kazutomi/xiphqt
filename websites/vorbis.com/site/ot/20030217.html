1. Status Updates

1.1. Monty

Continuing on his libogg coding spree, Monty has completed the zero copy rewrite of the bit packer and is in the process of testing and debugging this rewrite. He also fixed a small floating point exception in libvorbis that occurred in the floor line fitter when part of the spectrum fell under -140dB.

1.2. Jean-Marc Valin

Jean-Marc is busy preparing Speex RC3. There were minor bug fixes, documentation updates, and a change to the excitation codebooks in order to remove artifacts that occurred in some transients when the energy rose too quickly in the middle of a frame.

1.3. Michael Smith

Mike checked in tons of updates to icecast. There were lots of bug fixes and infrastructure improvements that are too numerous to list individually, but to mention one prominent example, icecast now fully supports IPv6.

1.4. Brendan Cully

Brendan added icecast 1.x dumpfile support and filled in the shout_version function.

1.5. Oddsock

Thanks to a large commit sent in by Oddsock, icecast 2 is getting YP listing support. Read more about this below.

2. Interesting Discussions

2.1. Vorbis on Playstation 2

Playstation developer David Etherton started a very lengthy thread with this message asking about implementing Vorbis on the Playstation 2. It didn't take long for the responses to point him to the Tremor integer decoder. David reviewed the options, and it seems he has decided that Tremor is the way to go. He proceeded to tweak Tremor to improve performance on the PS2's MIPS processor, and discusses a number of interesting ideas in the remainder of this thread.

2.2. Speex ACM Codec

While Speex support for VoIP applications is pretty good on the Linux side, Windows has a bit of a disadvantage because nobody has stepped up to the plate to write a Speex ACM codec. This is going to change, as this message indicates. X-Fixer and Brian Teague are going to work together to implement an ACM codec, which will bring Speex's outstanding quality to NetMeeting and allow good sounding connections between GnomeMeeting and NetMeeting.

3. Recent Developments

3.1. Icecast Goodies

Over the past two weeks, a lot has happened in icecast development to bridge the gap between icecast 1 and icecast 2. One feature that icecast 1 users missed in icecast 2 was YP listing support, which is now available to icecast 2 thanks to the efforts of Oddsock. You can read his announcement here.

Another recent development that should make it easier for icecast 2 to grow its user base is this inofficial icecast2 HOWTO, written by Kerry Cox. If you were toying with the idea of setting up an icecast server, but were intimidated by the lack of documentation, this HOWTO might give you just the push you need.

3.2. application/ogg blessed by IANA

The efforts of Linus Walleij, Silvia Pfeiffer, and others to gain official recognition for Xiph's open standards have reached the first milestone in getting the MIME type application/ogg officially assigned. You can read the details here.

3.3. New Software

More Vorbis aware software has been added to the Software section of vorbis.com. The new titles are:

  • Musicbrowzer, an audio player for Windows 2000/XP that is designed for an entertainment PC. It has playlist management, tag editing, and can use a remote control.

  • Total Recorder records streaming audio, Mic input, Line-in input as well as CDs and DVDs. The resulting files are saved on your computer's hard-drive. The latest version (4.1) now supports Vorbis.
