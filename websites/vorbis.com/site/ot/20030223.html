2. Interesting Discussions

2.1. Integer Speex

Rick Kane asked in this message if anyone has done any work for a version of Speex that can run on processors that don't support floating point math. Only a few hours later, Andrew Baker introduced himself to the mailing list with this message, and described in great detail his plans to do exactly that.

Andrew is going to target specific TI DSP's, and he will work in a somewhat backwards way: Instead of integerizing the code first, and then porting to an integer DSP, he is going to first port to a floating-point DSP, and then proceed to integerize the code to implement it on a fixed point DSP. Still, it is quite likely that this project will produce results that should make it easier to target other fixed-point processors.

If you're interested in embedded Speex implementations, this will be an interesting project to watch.

3. Recent Developments

3.1. Portables, Portables, Portables!

We promised that 2003 would be an interesting year, and it's really starting to get interesting. As you probably know too well, support for portable players is the only remaining advantage that MP3 has over Ogg Vorbis. Very soon, this advantage is going to disappear. That's right, in a few months you will be able to go to your local consumer electronics store and buy a digital music player that plays Ogg Vorbis files!

The most promising contender is the Neuros Digital Audio Player that was already mentioned a few weeks ago. It is now official that Xiph will provide a firmware for the Neuros that will enable it to play Vorbis files. You can find more details and the official Xiph press release here.

Another contender is the line of iRiver's digital media players. iRiver commissioned Xiph to evaluate the possibility of Vorbis playback on iRiver's devices, and the evaluation has concluded with the result that the provided development hardware is able to play Vorbis. Unfortunately, it is currently not known which devices are based on this development hardware. The cautious conclusion is that at least one model from iRiver's line of players has the necessary power to play Vorbis audio.

Now that the evaluation is completed, the next step is to implement a firmware that will actually play Vorbis. iRiver has expressed intent to commission Xiph for this step as well, but no formal agreement has been made yet.

More details will be posted when they become available.

3.2. Bringing Vorbis support to Nero software

Ahead Software, makers of the popular Nero CD burning software, have released an SDK that allows developers to add new audio formats to Nero, Nero Express, and NeroMIX, according to this web page. This means that Nero can support Ogg Vorbis through a third-party plug-in.

Any volunteers that are interested in gaining instant fame by providing such a plug-in, please step forward! On the Nero side, you'll have to deal with whatever documentation the SDK provides, but on the Vorbis side we'll help out as much as we can on the vorbis-dev mailing list or in #vorbis on irc.xiph.org. Good luck!
