2. Interesting Discussions

2.1. Running Icecast on Port 80 without root privileges

Bryan Jay Miller asked about the possibilities of running icecast on port 80, but without root privileges. Alan Bushnell suggested using firewall software (like iptables or netfilter) to redirect port 80 to an unprivileged port. Samuel Hathaway provided a link to cbs [Warning: this server might be down], a client-server tool for allowing unprivileged programs to bind to ports below 1024. Moritz Grimm pointed out that icecast 2 (in CVS) supports changing its UID and GID, and running within a chroot()'ed jail. Icecast 2 only needs to run as root long enough to bind to privileged ports and then can switch to a normal user.

3. New Developments

3.1. Open Letter from the Xiph.org CEO on the MP3 License Changes

In response to Thomson's decision to charge patent licensing fees for MP3 decoder software, Xiph.org CEO Emmett Plant has posted an open letter to Thomson.

3.2. Codec Test at c't

Robert Michel reports that the German IT magazine "c't" is running an online listening test between AAC, MP3, WMA and Vorbis. Robert's posting gives instructions in English for non-German speakers. Hurry if you want to participate, because the tests close at midnight on August 28.

3.3. alogg 1.0.4 Released

Vincent Penquerc'h released alogg 1.0.4, "a library which integrates Ogg/Vorbis to the Allegro game programming library."
