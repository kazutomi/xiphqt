1. Status Updates

The Ogg team is still pushing towards RC3 among other goals. Here is a quick update from some of the most active developers in the last few weeks.

1.1. Monty

Monty continues to tune and develop bitrate management. RC3 bitrate management will allow seperate configuration of minimum, maximum, and average bitrate over a user-selectable window size. Naturally, variable bitrate modes are still supported as Vorbis's strongest point. This is one of the final encoder features for a 1.0 Ogg Vorbis release.

1.2. Stan Seibert

Stan has been working hard on ogg123 and libao. He has branched Kenneth's kcarnold_work branch and his updates are available on his voslung_kc_20011011 branch. These updates include a rewrite of the buffering code to be much more simple and bug-free, working HTTP streaming, and much better signal handling. If you're an ogg123 user, we suggest you test out this new development and report any problems you encounter. Libao has some Linux/PPC bugs fixed in the OSS plugin.

1.3. Jack Moffitt

Jack been working towards an alpha release of icecast 2.0. This includes tons of build system work for icecast, ices, and libshout for Solaris, FreeBSD, and Win32. Many people have been testing builds from CVS, and this will be a chance for those interested in Ogg streaming to test on a wider scale. Jack also completed the Ogg MIDI work, bringing the first new substream to the Ogg framework. He and Ralph Giles are still working on the specification, which will be finished shortly.

1.4. Chris Wolf

Chris has been updating and documenting the Win32 build system. A portable nmake-based build system is now available, as well as a much updated an improved Developer Studio based one. There is much better documentation now as well. For details see win32sdk/README.win32sdk.

2. New Developments

Since the last official release a lot of work has been done in various areas.

2.1. Multicast Vorbis

Erik Kruus posted about his multicast Vorbis over RTP work. We now have the first implementation of the Vorbis RTP draft specification. It does not support chained streams yet, but this will hopefully be addressed in a future version of the specification and the draft.

2.2. Tarkin

Holger posted an update to the tarkin-dev list. Essentially the Tarkin code in the w3d module of CVS is now usable to a large extent. It produces compressed bitstreams, should have reasonable compression ratios, etc. There is currently not a player for Tarkin yet, but we hope to have one soon, as well as a specification for Tarkin inside Ogg bitstreams. Give it a whirl!

2.3. Ogg MIDI

Jack finished version 1 of the Ogg MIDI work, and a spec is forthcoming. The working code is in the ogg-tools module of CVS, and the tools to play with are oggmerge and omplay. oggmerge combines substreams into a single Ogg bitstream, and omplay plays Ogg files comprised of synchronized MIDI and Vorbis substreams. The code is pretty simple and serves as a model for future substreams.

2.4. Ogg MNG

Ralph Giles has been working on MNG substreams for Ogg for some time and did much of the foundation research and work that led to Ogg MIDI. He recently picked back up his work and we should have Ogg MNG streams pretty soon.

3. Interesting Happenings

A lot of mail comes in to the various lists as well as to the team's personal mailboxes. The following is a highlight of the interesting things that have been mentioned or announced.

3.1. BBC Ogg Broadcasts

Ciaran Anscomb of the BBC (yes, that BBC) has announced that they are testing scheduled Ogg broadcasts with icecast 2.0. You can tune into these broadcasts at http://support.bbc.co.uk/oggstreams.shtml. The page will be updated as new things are added.

3.2. Vorbis on Dreamcast

Thorsten Titze wrote in to inform us that he had ported Ogg Vorbis to the Dreamcast platform using the Open Source Dreamcast OS KallistiOS. This work will soon become part of the KallistiOS source tree.

3.3. Vorbis in Serious Sam

Alen Ladavac, the Lead Programmer of Croteam, wrote in to tell us that the next version of their game Serious Sam would ship with Ogg in their sound engine. In addition to being used in Croteam's games, it is also available to their engine licensees.

3.4. Ogg FLAC

Josh Coalson, author of FLAC, has added an option to the FLAC encoder to produce Ogg bitstreams. This will be interesting work especially once Ogg MNG is done, as we will have a great distribution format for lossless video.

3.5. Java Support for Ogg

JCraft has produced even more Java software that supports Ogg. They now have jRoar which is an icecast 2.0 compatible streaming server and proxy as well as jESD which is an ESD compatible sound server in Pure Java that also supports the sending of Ogg instead of raw audio. This is in addition to the Pure Java version of the Ogg Vorbis decoder and player jOrbis.

In a related note, idcmp pointed us to an RFE (Request for Enhancement) over at the Java Developer Center. If you are a Java developer and interested in Ogg Vorbis, this RFE could use your vote! It essentially requests that Ogg Vorbis become part of Java's multimedia infrastructure.
