1. We're Back!

After a 6 month hiatus, Ogg Traffic is back again. While OT has been quiet for a while, development has not slowed. Big things are brewing at Xiph.org, as you'll see in this week's Ogg Traffic update.

2. Status Updates

The Ogg team is gearing up for RC4. Here is a quick update on what some of the team members have been working on.

2.1. Monty

Monty has been spending a lot of time finishing the new encoder for RC4. Mainline CVS now has his "Grand Simplification" code available for testing. VBR encoding (only specifying a quality setting) is now running faster and producing higher quality files (quality 0 has been getting good reviews from the users in #vorbis IRC channel). Both stereo and mono modes at 44.1 and 48 kHz are available for testing in the CVS repository. VBR with bitrate constraints (max, min, and average) should also be working as well. The stereo coupling has gotten smarter, allowing the encoder to select the stereo mode with greater flexibility. In addition, the encoder is also exposing more adjustable parameters to the world, so some aspects of the encoding process can be tuned without modifying libvorbis directly. In the coming days, Monty will also be tuning the modes for use at sample rates below 44.1 kHz. The adventurous are invited to test the new code and let us know how it is working. As always, bugs (or other comments) should be reported to the vorbis development mailing list.

2.2. Michael Smith

Michael has been working on two things lately. First, he's been rewriting ogginfo to make it better at detecting errors in Ogg files and also to get it ready to work with Ogg files that contain something other than a single Vorbis stream. He has also been patching oggenc to allow more control over the encoding process. Oggenc allows the input audio to be resampled and downmixed on-the-fly before being encoded. Access to the new vorbis encoder options has also been added via the --advanced-encode-option key=value flag. Those interested in testing these new options should look at the set_advanced_encoder_options() function in oggenc/encode.c. The latest ogginfo and oggenc can be found in the vorbis-tools module in CVS.

3. New Developments

3.1. Ogg Theora Announcement

Last week, the Ogg Theora project was announced. Over the next year, Xiph.org will be integrating the VP3 video codec (contributed by On2 Technologies) into the Ogg multimedia framework to create an Open Source video solution. More details can be found in the Linux.com news article or the official Theora website.
