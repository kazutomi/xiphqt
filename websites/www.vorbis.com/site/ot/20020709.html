1. Status Updates

1.1. Monty

Monty has been working on tuning the sub-44.1 kHz encoding modes. Modes tuned for 32 kHz are already in CVS, with lower sample rates (8, 11, 16 and 22 kHz) soon to come. Give them a listen and let us know what you think. Monty has also been squishing various bugs in libvorbis and working on completing the Vorbis documentation.

1.2. Michael Smith

Michael has added a new utility to the vorbis-tools suite. Oggdec is a command line tool for decoding an Ogg Vorbis file to either a WAV file or raw samples. It is much easier to use than ogg123 for decoding to disk. Please check it out and provide us with feedback. Ices has been updated to support more Vorbis bitrate management options, and the playlist support has been improved. Michael has also been fixing up some bugs in libvorbis and updating some of the Windows project files.

1.3. Stan Seibert

Stan has been spending most of his time working on ogg123. Support for directory recursion and playlists has been added. Now specifying a directory on the ogg123 command line will add all of its files (and files in its subdirectories) to the list of files to be played. Playlists are text files containing one filename or directory name (or URL) per line which are specified using the -@ switch. Ogg123 compilation, along with all of the other vorbis tools, is now optional, so those of you missing ogg123 dependencies can now compile the rest of the vorbis tools without any problems.

1.4. Chris Cheney

Chris has been updating the Debian packaging files for the upcoming release. Debian packages will be available at release time thanks to Chris's work.

1.5. Segher Boessenkool

Segher fixed a build problem with vorbis-tools involving gettext that had been vexing a number of people.

2. New Developments

2.1. Ogg Theora Website

The Ogg Theora website has been updated with links to the Ogg Theora mailing lists and instructions on checking code out from CVS. Things are going to be quiet on Theora development until Vorbis 1.0 makes it out the door, but there are some things for you to look at.
