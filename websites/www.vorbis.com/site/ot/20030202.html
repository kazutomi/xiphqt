Jean-Marc continued reducing the data size for Speex by changing the LSP and Gain codebooks from float to signed short data. The result is Release Candidate 2 for Speex 1.0. Read his announcement below.

2. Interesting Discussions

2.1. PlusV for Ogg Vorbis?

This message points us to PlusV, which is a technology that promises to improve the quality of MP3 in much the same way as mp3PRO does, and the poster thinks that Ogg Vorbis should include PlusV to improve its quality.

As the responses mention, this topic has already been discussed in October 2002.

There are several problems with PlusV that impede inclusion in Ogg Vorbis. One is that PlusV development seems to have ceased, and when Monty originally looked into it, it didn't seem worth being included in Ogg Vorbis. Keep in mind that Ogg Vorbis is fundamentally different from MP3, and the fact that PlusV improves the quality of MP3 doesn't mean that it can improve Ogg Vorbis in the same way.

The other problem is that PlusV has patents pending. There is a royalty-free license for the patents, but that license only applies to GPL software and is therefore incompatible with Xiph's BSD-style licensing.

3. Recent Developments

3.1. FLAC joins Xiph.Org

This already made Slashdot, so it's not really news anymore, but just for the sake of completeness and any Xiph fans that don't read Slashdot, it is my pleasure to announce that the FLAC project has decided to join forces with the Xiph.Org Foundation. Okay, I know what you're all thinking, so let's get this joke out of the way:

We are Xiph.Borg! Your open multimedia technologies will be assimilated! Resistance is futile!

Anyway, jokes aside, it is Xiph's mission to provide patent-free and open multimedia standards, and lossless audio encoding was a missing piece of the puzzle. With FLAC filling that gap, Xiph now covers all audio needs from low-bitrate speech encoding with Speex to all-around versatility with Vorbis to lossless encoding with FLAC.

3.2. Speex RC2

Here is Jean-Marc's announcement for Speex RC2:

 

I'd like to announce the second release candidate for Speex 1.0. It fixes some minor bugs and reduces the binary size somewhat as the codebooks were converted from float values to chars. As a result of this, files encoded with earlier versions will have a slight increase in noise (typically less than 1 dB) when decoded with the newer decoder.

As with the last release, you are encouraged to test it, beat on it, and report bugs. If you want to know how you can make 1.0 better, have a look at the Roadmap page.

  
--Jean-Marc
