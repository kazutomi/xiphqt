Playing Files with Vorbis

This is the third of a four-part series of articles about Ogg Vorbis, a high quality, open source audio compression technology.

Last week, we introduced some of the mechanisms that Vorbis uses to encode audio. This week, we will briefly outline how to play Vorbis files and streams using some of the most common playback utilities.

How can I play Vorbis files in Windows?

One of the best Vorbis players for Windows is Winamp, which has shipped an ogg Vorbis decoder since version 2.80. (Note that the lite version does not include the decoder.)

How can I play Vorbis files when I'm using Linux or another unixlike operating system?

For Linux, the BSDs, and Unix operating systems, the two main vorbis players are ogg123, the command line utility, and XMMS for a graphical X-based player.
ogg123 is a simple command-line player that operates much like mpg123 and takes a list of .ogg files as arguments to the program. To skip to the next file, press Ctrl-c once. To stop playback, press Ctrl-c twice in two seconds.

How can I play Vorbis files in MacOS 9 or OS X?

Ogg Drop for OS X is capable of playing vorbis files, but it can't seek inside of a file as of this writing. In addition, Audion 2, Unsanity Echo, and Macamp all list Ogg Vorbis as one of the formats that they support.

How can I listen to a Vorbis stream...

...on Windows?

If you want to listen to a stream and are given a link in Internet Explorer, it's best to right-click on the link and select the "Copy Shortcut" option, and then paste that into Winamp's "Open Location" dialog by right clicking on the Load button.

...on Linux/UNIX with ogg123?

Simply run ogg123 with the stream as the input file, as in ogg123 http://www.example.com/stream.ogg.

...in Linux/UNIX with XMMS?

Select "Play Location" by right-clicking on the main XMMS window and paste or type the url. Control-L also brings up the same window.

...on MacOS?

As of this writing, there are no tools for MacOS that will play a Vorbis stream.

...with Java?

Jcraft's JOrbis is a free Java Vorbis player. It will decode streams from within a web browser with Java enabled.
