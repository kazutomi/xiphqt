Downloads.

The current version is 0.1.2. It is expected to work with the following system configuration:

  • Mac OS X - version 10.3.9 or 10.4 and later;
  • QuickTime for Mac OS X - version 7 or later;
  • Xiph frameworks - included in the full XiphQT binary package; see below for the separate frameworks package.

Starting with version 0.1.2 a full binary installer is provided which installs both the components and the Xiph frameworks.

For more details on features and changes see release notes.
