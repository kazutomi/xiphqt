Downloads.

The current version is 0.1.1. It is expected to work with the following system configuration:

  • Mac OS X - version 10.3.9 (not tested), 10.4 or later;
  • QuickTime for Mac OS X - version 7 or later;
  • Xiph frameworks - see below for the binary package.

Please note: for XiphQT to work the Xiph frameworks are required and, at the moment, they need to be installed separately.

For more details on features and changes see release notes.
