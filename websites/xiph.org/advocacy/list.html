Xiph.org Advocacy and Evangelism Mailing List June 28, 2001

The advocacy@xiph.org mailing list is intended for any and all discussion related to the promotion, advocacy, and evangelism of the Xiph.org projects.

Assuming that the email preferences in your web browser are set up correctly, the following button sends a subscription request directly to xiph.org. You'll get an email back with the result; the submit button does not take you to another page.

Tradiitonal method: send a message containing only the one-word line 'subscribe' in the body to advocacy-request@xiph.org. Do not send subscription requests directly to the main list; they will be silently ignored.

The list is archived on the xiph.org mailing list archive page.
