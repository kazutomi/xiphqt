Icecast: Mailing Lists February 24, 2001

Icecast User and General Discussion Mailing list

The icecast@xiph.org mailing list is intended for icecast discussion and user support.

Assuming that the email preferences in your web browser are set up correctly, the following button sends a subscription request directly to xiph.org. You'll get an email back with the result; the submit button does not take you to another page.

Tradiitonal method: send a message containing only the one-word line 'subscribe' in the body to icecast-request@xiph.org. Do not send subscription requests directly to the main list; they will be silently ignored.

The list is archived on the xiph.org mailing list archive page.
