Playing Ogg on windows

To play ogg audio (that is vorbis) files, you can use winamp.

You can install directshow filter, which will enable playback of Ogg files in windows media player. To install

  • Download Ogg Codecs for Windows.
  • Uninstall any previous version of these filters. Go to add remove programs, remove oggcodecs.
  • Make sure media player or any directshow applications are closed.
  • Unzip the file to a temp directory then run setup.

Real Player can also be used to play Ogg files. You will have to download and install codecs from helix community website.
