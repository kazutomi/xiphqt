Playing Ogg on Linux/Unix

All popular media players for Linux support Ogg files well. You can try out xmms, mplayer or xine. But make sure that libtheora is installed otherwise you wont be able to view video.

To install mplayer with ogg theora support first install libtheora (you will have to install libogg also). After installing libtheora, you can compile mplayer from source tarball.

If you want to install MPlayer using rpms, SuSE rpm available on packman.links2linux.org are good.
