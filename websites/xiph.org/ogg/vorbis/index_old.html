The Ogg Vorbis CODEC project December 31, 2001

Ogg Vorbis is a fully Open, non-proprietary, patent-and-royalty-free, general-purpose compressed audio format for mid to high quality (8kHz-48.0kHz, 16+ bit, polyphonic) audio and music at fixed and variable bitrates from 16 to 128 kbps/channel. This places Vorbis in the same competetive class as audio representations such as MPEG-4 (AAC), and similar to, but higher performance than MPEG-1/2 audio layer 3, MPEG-4 audio (TwinVQ), WMA and PAC.

Vorbis is the first of a planned family of Ogg multimedia coding formats being developed as part of Xiph.org's Ogg multimedia project.

News

Release update

Release Candidate 3 (1.0rc3) is now ready and tagged as 'vorbis1_0_public_release_candidate_3' in CVS

This is a full test release of a pre-1.0 encoder, decoder and tool set. The encoder, decoder and tools now implement all Vorbis 1.0 specification features including low-bitrate, cascading and channel coupling.

IMPORTANT WARNING
EGCS (new gcc) versions 2.91.xx have a serious floating point optimization bug that will prevent Ogg Vorbis from compiling correctly. The resulting build will run and produce Ogg files, but the audio quality will be severly damaged. gcc/egcs 2.91 is a quite old compiler, but RedHat shipped with this particular compiler until at least RedHat 6.2.

To determine the version of the compiler installed on your system, execute:
gcc --version

If the reported version is 2.91, upgrade your compiler as soon as possible. More than only Ogg is affected by this bug.

State of Vorbis

The current state of the Vorbis software library and tools:
libvorbis
libVorbis is the core Ogg stream / Vorbis engine.
Status: Release candidate, API stable.
libvorbisenc
libVorbisenc is an encoder setup library that provides easy encoder setup and encapsulates setup details to preserve binary compatability between library releases.
Status: Release Candidate, API stable.
libvorbisfile
vorbisfile is an ANSI C convenience library intended to simplify most applications and provide example code for functions such as seeking and error recovery.
Status: Full release.
code examples
example code that illustrates a simple encoder, decoder and file structure extractor.
Status: Full release.
OggEnc (vorbis tools)
'Standard' OggVorbis command line encoder providing multiple bitrate encoding and comment tagging.
Status: Full release.
Ogg123 (vorbis tools)
'Standard' OggVorbis command line decoder/player.
Status: Full release.
Ogginfo/Vorbiscomment (vorbis tools)
'Standard' OggVorbis information query and comment modification utilities.
Status: Full release.
Oggdrop (vorbis tools)
Graphical drag-and-drop encoder for the Win32 desktop.
Status: Full release.
player plugins
The full list of player plugins is now at the the Vorbis demo site.
documentation
Documents covering the complete Vorbis specification as well as the programming APIs for xiph.org's own libogg/libvorbis/libvorbisfile/libvorbisenc.
Status: In progress
