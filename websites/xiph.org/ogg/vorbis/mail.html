Ogg Vorbis: Mailing Lists February 11, 2001

Developer Mailing list

The vorbis-dev@xiph.org mailing list is intended for Ogg Vorbis developers to coordinate development of the Vorbis specification and the libvorbis software library. Please restrict discussion on the vorbis-dev lists to those topics.

Assuming that the email preferences in your web browser are set up correctly, the following button sends a subscription request directly to xiph.org. You'll get an email back with the result; the submit button does not take you to another page.

Traditional method: send a message containing only the one-word line 'subscribe' in the body to vorbis-dev-request@xiph.org. Do not send subscription requests directly to the main list; they will be silently ignored.

The list is archived on the xiph.org mailing list archive page.
