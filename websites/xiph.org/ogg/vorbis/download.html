The Ogg Vorbis CODEC download page

July 19, 2002

Release status

The current encoding tools, decoding tools and libraries are at 1.0 final release.

Prebuilt encoders and players, source packages, libraries and utilities are available for download from the Vorbis site download directory.

Full developer-ready distributions may be checked out from the live xiph.org Subversion repository (module names 'ogg' for libogg, 'vorbis' for libvorbis, libvorbisfile and libvorbisenc, 'ao' for libao, used by ogg123, 'vorbis-tools' for the vorbis command line utilities, and 'Tremor' for the integer-only Vorbis decode library named 'Tremor'). Official 1.0 source tarballs are available in the local vorbis download directory.

...and don't forget to drop some spare cash in the collection plate before running off to enjoy your shiny, new, state-of-the-art codec.

State of Subversion

The bitstream format for Vorbis 1.0 was frozen Monday, May 8th 2000. All bitstreams encoded since will remain compatible with all future releases of Vorbis.

The code in Subversion is now all at 1.0 final release.

The Subversion mainline is suitable for designing, building and integrating Vorbis into applications. It may be used to build production bitstreams at this point.

If you wish to contribute to the Ogg Vorbis codec, please contact us via the developer mailing list.
