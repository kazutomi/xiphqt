The Ogg Vorbis CODEC project

Ogg Vorbis is a fully open, non-proprietary, patent-and-royalty-free, general-purpose compressed audio format for mid to high quality (8kHz-48.0kHz, 16+ bit, polyphonic) audio and music at fixed and variable bitrates from 16 to 128 kbps/channel. This places Vorbis in the same competitive class as audio representations such as MPEG-4 (AAC), and similar to, but higher performance than MPEG-1/2 audio layer 3, MPEG-4 audio (TwinVQ), WMA and PAC.

Vorbis is the first of a planned family of Ogg multimedia coding formats being developed as part of Xiph.org's Ogg multimedia project.

News

"Tremor" integer-only codec now under BSD license

The "Tremor" decoder library, an integer-only, fully Ogg Vorbis compliant software decoder library is now available under a totally free BSD-like free software license. Download complete source code as a a tar.gz format archive, or check out module 'Tremor' from Xiph.Org CVS.

Discussion of Tremor is welcomed on the Tremor mailing list, tremor@xiph.org.

Release update

We made it! Ogg Vorbis has hit 1.0! Get your official downloads from http://www.vorbis.com/download.psp or peruse 1.0's mid and low bitrate quality on our codec comparison page with downloadable test samples. CVS is tagged as 'vorbis1_0_public_release' in CVS.

This is a full release of a 1.0 encoder, decoder and tool set. The encoder, decoder and tools now implement all Vorbis 1.0 specification features including low-bitrate, cascading and channel coupling.

State of Vorbis

The current state of the Vorbis software library and tools:
libvorbis

libVorbis is the core Ogg stream / Vorbis engine.
Status: Full release.

libvorbisenc

libVorbisenc is an encoder setup library that provides easy encoder setup and encapsulates setup details to preserve binary compatability between library releases.
Status: Full release.

libvorbisfile

vorbisfile is an ANSI C convenience library intended to simplify most applications and provide example code for functions such as seeking and error recovery.
Status: Full release.

code examples

Example code that illustrates a simple encoder, decoder and file structure extractor.
Status: Full release.

OggEnc (vorbis tools)

Standard Ogg Vorbis command line encoder providing multiple bitrate encoding and comment tagging.
Status: Full release.

Ogg123 (vorbis tools)

Standard Ogg Vorbis command line decoder/player.
Status: Full release.

Ogginfo/Vorbiscomment (vorbis tools)

Standard Ogg Vorbis information query and comment modification utilities.
Status: Full release.

Vcut (vorbis tools)

vcut splits an Ogg file into two files with sample-level accuracy.
Status: Full release.

Oggdec (vorbis tools)

oggdec decodes an Ogg Vorbis file to either a WAV file or raw PCM.
Status: Full release.

Oggdrop (vorbis tools)

Graphical drag-and-drop encoder for the Win32 desktop.
Status: Full release.

documentation

Documents covering the complete Vorbis specification as well as the programming APIs for xiph.org's own libogg/libvorbis/libvorbisfile/libvorbisenc.
Status: Full release

Distribution Terms in Plain English

However, Xiph.org and the Ogg project (xiph.org) reserve the right to set the Ogg/Vorbis specification and certify specification compliance.

Xiph.org's Vorbis software libraries (libvorbis and vorbisfile) are distributed under a BSD-like license; these libraries may be used by any application, Open or proprietary, linked or incorporated in whole, so long as acknowledgement is made to Xiph.org Foundation when using our codec source in whole or in derived works. See the file 'COPYING' in the source for all the details.

All other portions of xiph.org's reference Vorbis software are distributed under the (GNU) Library General Public License (LGPL).

Because the specification is open, third parties are welcome (and encouraged) to implement third party Vorbis software under other licenses using xiph.org's reference source as an authoritative reference.
