Neurosetta

Neurosetta is an updated firmware for the Neuros Audio Computer which enables the Neuros to play Ogg Vorbis files.

Current Status

Beta 1.40a: Vorbis support has been integrated with MP3 and WAV playback in the latest beta firmwares from Digital Innovations. The Neuros beta firmware page lists version 1.40 as the latest version, but there was an unofficial bug fix release (called "1.40a") on open.neurosaudio.com that corrected some Vorbis-related problems. This version is also mirrored below.

Instructions

Please note that you can both upgrade and downgrade firmware on the Neuros. It should be pain-free to try out this firmware and then switch back if you find it necessary.

(Firmwares from neurosaudio.com are packaged as self-extracting Windows Executables. If you are on a non-Windows system, you can unpack them using a standard unzip program.)

Prepare: Turn off automatic sync in the Neuros Sync Manager before beginning.

  1. Turn off the Neuros. Unplug the power cord and USB cable.
  2. Press the down button and the power button at the same time.
  3. Follow on-screen instructions to connect USB cable.
  4. Windows
    Open up the Neuros Removable drive in Windows Explorer.
    Linux
    Mount your Neuros.
  5. Copy the woid.hex file into the firmware directory on the Neuros. If that directory doesn't exist, create it. If there is already a woid.hex file there, overwrite it. If you're using Linux, unmount the Neuros.
  6. Wait for the USB IDLE message to appear on the Neuros.
  7. Unplug the USB cable from the Neuros and follow the on-screen instructions to complete the installation.

To upload Ogg Vorbis files to the Neuros, you will need to follow the instructions for enabling Vorbis support in positron.
