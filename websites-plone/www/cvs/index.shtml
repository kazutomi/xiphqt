Modules

Module name Description
ao Source code to libao, used by some vorbis utilities.
ao-python Python bindings to libao.
icecast The icecast2 streaming audio server.
ices An audio source client to the icecast2 server.
libshout A library for communicating with an icecast server.
masktest Source code to a package that collects masking data from a user by running listening experiments.
mgm MGM is a status/load meter written in Perl.
ogg Source code to libogg.
ogg-python Python bindings for libogg.
ogg-tools Source code to various command line utilities for other types of Ogg files.
paranoia-III Source code to cdparanoia and Paranoia III.
speex Source code to the Speex low-bitrate voice-only audio codec.
tarkin Source code to Tarkin, an experimental video codec.
theora Source code to Theora, a video codec.
Tremor Source code to Tremor, the integer-only Ogg Vorbis decode library.
vp32 Source code to ON2's VP3.2 video codec.
vorbis Source code to libvorbis, libvorbisfile, libvorbisenc, and example code.
vorbis-plugins Source code to a few Ogg Vorbis player plugins:
  • Winamp 2 (though Winamp 2 bundles a better plugin)
  • kmpg (a KDE 2.0 media player)
  • RealPlayer 8
vorbis-python Python bindings for libvorbis, libvorbisfile and libvorbisenc.
vorbis-tools Source code to various command-line Ogg Vorbis utilities, including ogg123, oggdec, oggenc, ogginfo, vcut, and vorbiscomment.
w3d Source code to another Tarkin experiment.
win32-tools Source code for Windows-specific tools, including oggdrop.
win32sdk The Windows development SDK.
