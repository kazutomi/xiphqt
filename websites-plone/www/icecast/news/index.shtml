Icecast: Open, Free, Streaming Audio

Icecast is an audio broadcasting system that streams music in the Ogg Vorbis format.

Have more questions? Have a look at the FAQ .

News

  1. IceS 0.3 released

    2003-07-13

    IceS 0.3 has been released. This release requires libshout 2.0. Among the new features are Icecast 2 compatibility, ID3v2 support, much improved stability, and VBR support. All users of IceS 0.2.3 or earlier are strongly encouraged to upgrade.

  2. libshout 2.0 released

    2003-07-13

    At long last, libshout 2.0 has been released. This release features Vorbis, Icecast 2 and IPv6 support, as well as bug fixes. It is not API-compatible with libshout 1.0.

  3. Icecast 1 resuscitated

    2003-02-12

    We’ve re-added the deprecated, unsupported Icecast 1 to the download page since people ask for it. We’ve also added a contact page to point out how you can best get in touch with real humans in case this Web site doesn’t give you all the answers.

  4. Icecast.org relaunched

    2003-01-22

    After months of no apparent activity, icecast.org has finally been updated. Since the old site abused markup somewhat (like using <table>s for layout), we redesigned with a <table>-free CSS layout adorned with the occasional PNG image.

    Some of the older stuff will gradually make it back on-line—the patent-encumbered GIF images will not.

    We redid the Icecast logo in SVG and then generated PNGs to use on the site. If you’d like a pristine copy of the Icecast logo, grab cauldron.svg.

  5. IceS 0.2.3 released

    2002-05-01

    IceS 0.2.3 has been released. This release removes threading code and includes the latest libshout, making it more stable and portable—it should now build on OS X. It will also reload your playlist script when given the SIGHUP signal.

  6. Icecast 1.3.12 released

    2002-04-10

    Icecast 1.3.12 has been released. This release is a security update and all users are highly encouraged to upgrade immediately or apply the relevant patches to their own versions. Remember, never run icecast as a privileged user, and especially not as root.
