Ogg Vorbis: Open, Free Audio Compression

Ogg Vorbis is a non-proprietary, patent-and-royalty–free, general-purpose compressed audio format for mid- to high-quality audio and music at variable bitrates from 16 to 128 kbps per channel.

This places Vorbis in the same class as MPEG-4 (AAC) and above MP3 and WMA.

Vorbis Stuff

Libraries

libvorbis
libvorbis is the core Ogg stream/Vorbis engine.
libvorbisenc
libvorbisenc is an encoder setup library that provides easy encoder setup and encapsulates setup details to preserve binary compatability between library releases.
libvorbisfile
vorbisfile is an ANSI C convenience library intended to simplify most applications and provide example code for functions such as seeking and error recovery.

Vorbis Tools

oggenc
Ogg Vorbis command-line encoder with bitrate/quality level configuration and comment tagging.
ogg123
Standard Ogg Vorbis command-line decoder/player.
ogginfo/vorbiscomment
Standard Ogg Vorbis information query and comment modification utilities.
vcut
vcut splits an Ogg Vorbis file into two files with sample-level accuracy.
oggdec
oggdec decodes an Ogg Vorbis file to either a WAV file or raw PCM.
oggdrop
Graphical drag-and-drop encoder for Windows.
