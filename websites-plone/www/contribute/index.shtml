Contribute to Xiph.org

You’d like to help us? Great! Here’s a non-exhaustive list of things that need doing:

General Stuff

  • Add in support for one or more Xiph codecs into your application.
  • Improve codec support in an application you wrote. There are a number of fancy things you can do with Vorbis-style comments; some ideas are available on our QA page.
  • If you know a standards body that needs audio compression, suggest a Xiph codec like Vorbis, FLAC, or Speex.
  • Write (or improve) a plugin for your favorite codec in your favorite audio player.

Vorbis Stuff

  • Document the reference encoder.
  • Write a free, open-source fixed-point encoder for processors without FPUs.

FLAC Stuff

  • Modify the Winamp plugin for FLAC so it supports UTF-8.
  • Complain about the sorry state of liboggflac.
  • Write a tool to transcode from native FLAC to Ogg FLAC. Extra kudos if your tool handles the return trip.

Speex Stuff

  • Write a free, open-source fixed-point encoder for processors without FPUs.
